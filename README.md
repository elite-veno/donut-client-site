# Donut Client site

The landing page for Donut Client, where players buy a 2-month key for $10. It is one static page (`index.html`) served by GitHub Pages.

## Opening sales

Every buy button reads one link: `CHECKOUT_URL` in the script at the bottom of `index.html`. While it is empty, the buttons scroll to the pricing card, which says checkout opens soon. Paste a checkout link there (for example a Lemon Squeezy buy link for a $10 product whose license keys last 2 months), commit, and push; Pages republishes within a minute.

## Preview

Open `index.html` in a browser. It needs no build step.
